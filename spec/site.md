# The site

**Status:** Built; live at qdeco.com. **Open work:** B-4, B-5.

What qdeco.com is made of and how it is published. This was the "What
the site is" section of `spec/status.md`, moved here word for word on
2026-10-09.

- **qdeco.com** = GitHub Pages serving `main` of **JasonHunt3r/Qdeco** (public),
  the repo root, with `CNAME`. A push to `main` is a publish (live in ~1 minute).
  Plain static HTML: no Jekyll config, no build step.
- `index.html` — the one page ("On the Margins", title "Qdeco Presenter Demo"):
  the IO-marker demo, sections Qdeco / RhythmIO / BGTools / UP Scaler / About /
  Support, Settings (Calm, Desktop, resets). Icons inline as WebP data URLs.
- `privacy.html`; `html2canvas.min.js` (self-hosted, no Cloudflare request);
  the three app icon PNGs; `edit.js` (edit mode, below).
- Retired pages kept in the repo: `index-retired-2026-10-09.html`,
  `index-retired-2026-10-09b.html`.
